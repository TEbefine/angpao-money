# ราพสลัด — แอปหน้าร้าน

PWA ไฟล์เดียว ไม่มี build step เปิดติดใน ~0.3 วิ ใช้ได้ตอนเน็ตหลุด

## 1. ลองใช้เลย (ยังไม่ต้องต่อ Supabase)

เปิด `index.html` ในมือถือ → PIN `1111`

ข้อมูลเก็บในเครื่อง ใช้ได้ครบทุกฟังก์ชัน ขาดอย่างเดียวคือไม่ซิงก์กับเครื่องเพื่อน

## 2. ขึ้นเว็บจริง

ลากโฟลเดอร์นี้ทั้งอันเข้า Vercel หรือ Netlify — ไม่ต้อง build อะไร
เปิดในมือถือ → เมนู browser → **Add to Home Screen** → ได้ไอคอนบนจอ เปิดจากไอคอนได้เลย ไม่ต้องพิมพ์ URL

## 3. ต่อ Supabase (สองเครื่องเห็นตรงกัน)

1. สร้าง project ใหม่ (Singapore)
2. SQL Editor → วาง `schema.sql` ทั้งไฟล์ → Run
3. **Settings → API → Exposed schemas → เพิ่ม `rap`** ← ข้อนี้ลืมไม่ได้ ไม่งั้นซิงก์ไม่ขึ้น
4. ในแอป → ตั้งค่า → ใส่ Project URL + anon public key → บันทึก

## โครงต้นทุน

| กอง | ของ | คิดยังไง |
|---|---|---|
| `shared` | ผัก แป้ง น้ำจิ้ม ถ้วย ถุงมือ | ยอดซื้อทั้งหมด ÷ ม้วนทั้งหมด |
| `topping` | แซลมอน กุ้ง ไก่ ปูอัด | ยอดซื้อของไส้นั้น ÷ ม้วนของไส้นั้น |
| `equipment` | เตา ถาด กะละมัง | ไม่หารเข้าม้วน → ดู % คืนทุน |

ไม่ต้องชั่งอะไรเลย ไม่ต้องกรอกว่าเปิดกี่แพ็ค — แอปคิดจากจำนวนม้วนที่นับได้แม่นอยู่แล้ว
เป็น running average ยิ่งขายยิ่งแม่น ประมาณม้วนที่ 150 (4 สัปดาห์) ตัวเลขจะนิ่ง

## หลักที่ยึดในโค้ด

- **append-only** — ลบ = insert แถว `void_of` ทับ ของเดิมไม่หาย เปลี่ยนวิธีจ่าย = insert `pay_changes`
- **price snapshot** — ราคาถูกถ่ายไว้ตอนขาย แก้ราคาวันนี้ไม่กระทบเมื่อวาน
- **optimistic update** — กดแล้วเลขขึ้นทันที ไม่รอ server เน็ตหลุดก็ยังขายได้
- **outbox** — ที่ยังส่งไม่ขึ้นคิวไว้ ต่อเน็ตแล้วส่งเอง กันข้อมูลหาย
- **idempotent** — id สร้างฝั่ง client ส่งซ้ำก็ไม่เกิดรายการซ้ำ
- **local-first** — เปิดมาวาดจอจากเครื่องก่อน แล้วค่อยเช็ค server เบื้องหลัง

## ไฟล์

